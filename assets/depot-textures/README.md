# Depot textures (the source pictures)

The 3D depot's textures as Higgsfield made them, one picture per material, named after it
(any of `.png`, `.jpg`, `.webp`). `python3 tools/depot-textures.py assets/depot-textures` makes
`ui/img/depot/detail.jpg` from them; a material without its picture gets a neutral layer.

| File | What it is |
|---|---|
| `asphalt` | fine grey asphalt (the yard) |
| `road` | worn road asphalt with patches |
| `concrete` | concrete floor slabs, 2 × 2 |
| `grass` | mown lawn with clover |
| `earth` | soil seen from the side, with stones and roots |
| `cladding` | steel sandwich panels with fine ribs |
| `roofsheet` | trapezoidal roof sheet, ribs upright, screws |
| `shutter` | roller shutter slats |
| `brick` | red brick wall |
| `plaster` | rendered plaster with hairline cracks |
| `paving` | square grey paving tiles, 5 × 5 |
| `gravel` | pea gravel (flat roofs) |
| `tiles` | white wall tiles of the wash bay |
| `washfloor` | wet wash floor with a drain in the middle |
| `epoxy` | coated workshop floor with tyre tracks and oil |
| `formwork` | fair-faced concrete with tie holes (parking hall) |
| `blocks` | concrete block wall |
| `paint` | worn white road paint |
| `cracks` | black cracks on white |
| `tyres` | two tyre tracks on white |
| `oil` | oil stains on white |
| `manhole` | a manhole cover on white |
